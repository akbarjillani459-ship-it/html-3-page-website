Three-Page Website Using HTML & CSS
About the Project

This project is a three-page website created as part of a web development assignment. It is built using HTML and CSS to demonstrate basic website structure, styling, and navigation.

Pages
Home Page: Introduces the website.
Page 2: Displays the main content of the website.
Page 3: Provides additional information.
Technologies Used
HTML5
CSS3
Features
Three interconnected web pages
Navigation between pages
Simple and attractive design
CSS styling and layout
How to Run
Download or clone this repository.
Open index.html in a web browser.
Navigate through the website using the navigation links.
Purpose

This project was created for educational purposes to practice HTML and CSS.
